# Тесты для класса BooksCollector

Этот проект содержит набор автотестов для класса `BooksCollector`, который управляет коллекцией книг, их жанрами и избранным.

## Список тестов

### 1. `test_add_new_book_add_two_books` (пример)
- Проверяет, что метод `add_new_book` корректно добавляет и одну, и две книги.
- Ожидаемый результат: словарь `books_genre` содержит ровно 2 записи.

### 2. `test_add_new_book_valid_name` (параметризованный)
- Проверяет добавление книги с валидным именем (до 40 символов), слишком длинным (>40) и пустым.
- Ожидаемый результат: валидное имя появляется в словаре с пустым жанром, невалидные – не добавляются.

### 3. `test_add_new_book_duplicate`
- Проверяет, что одна и та же книга не добавляется дважды.
- Ожидаемый результат: в словаре остаётся только одна запись.

### 4. `test_set_book_genre` (параметризованный)
- Проверяет установку жанра для книги.
- Сценарии: валидный жанр, невалидный жанр, попытка установки для отсутствующей книги.
- Ожидаемый результат: жанр устанавливается только при валидных условиях.

### 5. `test_get_book_genre` (параметризованный)
- Проверяет получение жанра книги по её имени.
- Сценарии: книга существует, книга отсутствует.
- Ожидаемый результат: возвращается корректный жанр или `None`.

### 6. `test_get_books_with_specific_genre` (параметризованный)
- Проверяет поиск книг по указанному жанру.
- Сценарии: есть книги с жанром, нет книг с жанром, жанр не входит в общий список.
- Ожидаемый результат: возвращается список названий книг (или пустой список).

### 7. `test_get_books_genre`
- Проверяет, что метод `get_books_genre` возвращает весь словарь `books_genre` без изменений.

### 8. `test_get_books_for_children` (параметризованный)
- Проверяет, что в список детских книг попадают только те, чей жанр не имеет возрастного рейтинга (не входит в `genre_age_rating`).
- Сценарии: разные жанры, включая пустой.
- Ожидаемый результат: книги с разрешёнными жанрами присутствуют, с запрещёнными – отсутствуют.

### 9. `test_add_book_in_favorites` (параметризованный)
- Проверяет добавление книги в избранное.
- Сценарии: книга существует и ещё не в избранном, книга уже в избранном, книга отсутствует в словаре.
- Ожидаемый результат: книга добавляется только если она существует и ещё не добавлена.

### 10. `test_delete_book_from_favorites` (параметризованный)
- Проверяет удаление книги из избранного.
- Сценарии: книга есть в избранном, книги нет в избранном.
- Ожидаемый результат: книга удаляется только если она там была, иначе список не меняется.

### 11. `test_get_list_of_favorites_books`
- Проверяет, что метод `get_list_of_favorites_books` возвращает актуальный список избранных книг.

## Параметризация
В тестах активно используется `@pytest.mark.parametrize` для сокращения дублирования кода и проверки нескольких сценариев в одном тесте.

## Запуск тестов
Для запуска всех тестов выполните в терминале из корня проекта:

```bash
pytest -v tests.py
